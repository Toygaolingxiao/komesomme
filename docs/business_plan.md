# KomeSomme 事業概要

## 背景と価値

日本のブランド米は選択肢が多く、銘柄名だけでは粒感、甘み、粘り、料理や酒との相性を比較しにくい。KomeSomme は味わいマップと自然言語による意味検索で、利用者が用途に合う一膳へ到達するまでの迷いを減らす。

## 主な利用者

- カレー、刺身、おにぎり、弁当など料理に合う米を選びたい人
- 粒感や甘みの好みから新しい銘柄を探したい人
- ウイスキーや日本酒と合わせるご飯を探したい人
- ブランド米やふるさと納税返礼品を比較したい人

## 現行 MVP と収益化

現行 MVP は約 90 銘柄の座標推薦、意味検索 Top 4、銘柄詳細、楽天 / Amazon / ふるさと納税の検索 CTA を提供する。楽天 Affiliate API と成果計測は将来要件であり、現時点の実装済み収益とは扱わない。
