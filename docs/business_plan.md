# KomeSomme 商业企划书

## 1. 项目背景与愿景
- **痛点：** 日本品牌米种类繁多（越光、新之助、つや姫等），消费者在购买日常食用米或选择年底“故乡纳税”返礼品时，往往缺乏直观的决策依据。
- **愿景：** 打造日本最直观、智能的“大米选购与料理搭配指南”，年内跑通 B2C 盈利闭环，并为明年的农业 DX / 地方创生咨询业务积累标杆案例。

## 2. 目标客群 (Target)
1. **料理こだわり層（精致饮食与主妇群体）：** 追求“Food Pairing”，寻找最适合做咖喱、饭团、冷便当或刺身丼的大米。
2. **故乡纳税冲刺大军（10月~12月核心流量）：** 预算充足但面对海量返礼品无所适从的理性消费者。

## 3. 变现路径 (Monetization)
- **Amazon アソシエイト：** 日常品牌米的购买转化。
- **楽天ふるさと納税 / さとふる：** 年底故乡纳税大米返礼品的高客单价佣金。
