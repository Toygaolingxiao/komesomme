# KomeSomme UI デザイン仕様

この文書を KomeSomme の UI デザイン正本とする。旧 `1637_change.md` と `design_change.md` の有効な要件を統合し、今後の UI 実装・レビューは本書を基準にする。

## 1. 体験コンセプト

KomeSomme は、AI ダッシュボードではなく「和紙の味わい地図に触れ、炊きたての一膳を選ぶ」体験である。AI やベクトル検索は裏側に置き、画面では米、産地、料理との相性を主役にする。

- 印象: 明るい、温かい、静か、上質、触感がある
- モチーフ: 明るい和紙、炊きたての米、稲わら、淡い墨
- UI の役割: 味の位置を直感的に選び、推薦の優先順位を迷わず読めること
- 動き: 短い fade、穏やかな spring、探針の淡い ripple。派手な bounce、回転、走査線は使わない

## 2. カラーと質感

基本色は次の4系統とし、白一色や純黒を避ける。

- **Rice white**: `#F7F2E8` 前後。ページと和紙面の基調
- **Warm cream**: `#EFE3CD` 前後。面の差、入力背景、区切り
- **Ink brown**: `#3D2B1F` 前後。本文、軸、主要な輪郭
- **Rice-straw gold**: `#B77B45` 前後。No.1、探針、主要 CTA の限定アクセント

背景には低コントラストの繊維・紙粒子を薄く重ねる。装飾は情報を妨げない強度にし、強い glow、純黒、neon、寒色主体の glassmorphism は使わない。

地域色は補助情報に限定し、低彩度・同程度の明度で揃える。例:

- 北海道・東北: muted sage
- 関東・甲信越: straw ochre
- 東海・北陸: clay beige
- 近畿: warm sand
- 中国・四国: olive gray
- 九州・沖縄: muted terracotta

通常点は地域色を控えめに使い、No.1 は rice-straw gold、No.2〜4 は ink brown / gold の階層を優先する。

## 3. 味わいマップ

### 軸

- X 軸: **粒感**。データ上のフィールドは `hardness`
  - 左: やわらか
  - 右: しっかり
- Y 軸: **甘み**。データ上のフィールドは `sweetness`
  - 下: すっきり
  - 上: ふくよか
- `stickiness`（粘り）は点サイズと詳細表示に使い、座標軸にはしない

四象限は「やわらかく甘み豊か」「粒立ちよく甘み豊か」「軽やかですっきり」「粒立ちよくすっきり」と明快に示す。中央線は通常グリッドより少し濃くするが、教材図のように強調しすぎない。

### 点と探針

- 銘柄点は米粒を思わせる小さな楕円とし、`stickiness` に応じて控えめにサイズを変える
- No.1 は常時ラベル表示、No.2〜4 は小ラベルまたは hover / focus 表示、その他は tooltip とする
- 同一座標の銘柄は決定的な小オフセットで重なりを避ける
- 探針は金色の小点と淡い波紋で表現し、十字照準や HUD にしない
- 選択状態は色だけでなく、輪郭、サイズ、ラベルでも識別できるようにする

マップクリック、探針ドラッグ、スライダー操作は `hardness × sweetness` の座標推薦だけを即時更新する。LLM や意味検索を起動しない。

## 4. 情報設計

### Desktop

Desktop は左右2カラムで、ビューポート内に主要操作と推薦を収める。

```text
┌──────────────────────────────────────┬──────────────────────────┐
│ 風味マトリクス                        │ 侍米師のおすすめ           │
│                                      │ No.1                     │
│ [ 大きな味わいマップ ]                │ 近い味わい No.2〜4         │
│                                      │ 侍米師に相談               │
│ [ 現在値: 粒感 ][ 現在値: 甘み ]      │ [入力][提案]               │
└──────────────────────────────────────┴──────────────────────────┘
```

- 左: マップ、その直下に横並びの「現在の味わい」
- 現在値は粒感・甘みの数値、状態語、スライダーを各1組にまとめる
- 右: No.1、近い銘柄 No.2〜4、侍米師への相談だけを置く
- 右カラムに `overflow-y-auto` や専用スクロールバーを設けない
- No.1 は主カード、No.2〜4 はコンパクトな行リスト、相談は短い入力と CTA にする
- 詳細ダイアログなど一時的なオーバーレイは、内容量に応じて独立スクロールしてよい

### Mobile

Mobile は単列で、ページ全体の自然な縦スクロールを使う。

1. ヘッダー
2. タイトルと説明
3. 味わいマップ
4. 現在の味わい（粒感、甘み）
5. No.1
6. No.2〜4
7. 侍米師に相談

横スクロールを発生させず、マップ点、スライダー、ボタンには十分なタップ領域を確保する。

## 5. 推薦表示

- **座標推薦**: クライアントで `hardness × sweetness` の距離を計算し Top 4 を即時表示
- **意味検索**: 相談フォーム送信時だけ `/api/recommend` を呼び、Gemini embedding と Supabase pgvector による Top 4 を表示
- 意味検索結果は探針座標を上書きしない。「座標に戻す」で現在座標の Top 4 に戻す
- No.1 は銘柄、産地、相性、短い理由、粒感・甘み・粘りを表示
- No.2〜4 は順位、銘柄、相性、短い差分説明を表示
- 銘柄詳細には説明、相性料理、3指標、近い銘柄、楽天 CTA を表示

## 6. データフローを守る

既存の実データフローを維持する。

```text
初期表示
Browser → Supabase rice_brands → 味わいマップ

座標推薦
Map / sliders → client-side distance → Top 4

意味検索
相談文 → POST /api/recommend
       → Gemini gemini-embedding-001 (1536次元)
       → Supabase RPC match_rice_brands / pgvector
       → JSON Top 4 → 推薦欄

シード
seed-rice.json → Gemini embedding → Supabase rice_brands
```

Supabase を mock data に置き換えない。Gemini による embedding と pgvector 検索を削除しない。UI 改修のために未導入の UI / chart 依存を追加しない。

## 7. 状態とアクセシビリティ

- Loading: 米粒状の静かな pulse と日本語テキスト
- Empty: 銘柄未登録であることと次の行動を表示
- Error: 利用者向け文言と再試行を表示し、技術詳細は開発時だけにする
- `prefers-reduced-motion` を尊重する
- 入力には label、ボタンと点には明確な focus / disabled 状態を付ける
- tooltip だけに情報を依存させず、キーボードでも銘柄詳細を開ける

## 8. 禁止事項

- 教材的な水色方眼・グラフ用紙背景
- 赤い太枠
- 派手なカプセルや pill の大量使用
- 高彩度な地域色、neon、cyberpunk、AI dashboard 表現
- 全銘柄ラベルの強制常時表示
- Desktop 右推薦カラムの内部スクロール
- スライダーやマップ操作からの意味検索呼び出し
- 実データを mock data に差し替えること

## 9. 受け入れ基準

- 明るい和紙と炊きたて米の温度感が、色・余白・質感から伝わる
- X=粒感、Y=甘みが一目で理解でき、粘りは点サイズまたは詳細で読める
- Desktop は左にマップと横並び現在値、右に No.1・近い銘柄・相談が収まり、右側スクロールがない
- Mobile は単列で自然に操作できる
- 座標推薦と意味検索が混ざらず、どちらも Top 4 を表示する
- Supabase / Gemini / pgvector / 楽天 CTA の現行データフローが保たれる
