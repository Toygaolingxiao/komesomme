# UX 改善ロードマップ

2026-08 時点の **UX Phase 1–6 の完了記録**。未完了の本番タスクは [11-launch-checklist.md](./11-launch-checklist.md)。**現行の購入 UI / 頂栏の正本は [08-ui-design.md](./08-ui-design.md)**（本書のグリッド記述は歴史記録）。

## 変えないもの

- 推薦式・座標式
- 銘柄打分は合意プロセスなしに変えない（再校正は `scripts/data/` の正本経由）
- mock データ、勝手な seed

案内役は「侍米師（じべいし）」。禁止語: 最強 / 圧倒的 / 究極 / 唯一無二 / 爆発 / 神 / 無敵。米ソムリエ／コメソムリエは使わない。

## ベースライン評価（改善前）

世界観は伝わるが、初見の操作理解と購入までの導線が弱かった（総合 6.2 / 10）。離脱の主因は興味不足ではなく「次に何をすればよいか」が弱いこと。

## 決定済み方針（歴史 → 現行への読み替え）

| 当時の決定 | 現行（0.6.x） |

| `sm+` は 2 行 × 3 列の購入グリッド | **通販 / ふるさと納税** タグ。通販 4 / ふるさと 3。ホーム compact は 2×2、ライブラリは縦一列（軟色） |

| 文言は「探す」。EC のレジ画面にしない | そのまま |
| Mobile 地図は今日の一膳の下 | そのまま |

正本は `/library/[id]`（旧 `/{id}` は永久リダイレクト）。

```text
Hero → 品鑑（メモ・指標・料理）→ 購入（通販 / ふるさとタグ）
  → 由来 → 季節と飲み物 → 炊飯 → 似ている銘柄
```

（歴史: Hero → 上部 CTA 最大 2 → … → 下部 2×3。再設計済み。）

## 理想導線（ユーザータイプ別）

| タイプ | 導線 |
| --- | --- |
| A 何も分からない | 今日の一膳 → 理由 → ライブラリ事典 → お店で探す |
