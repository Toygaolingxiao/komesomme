案内役は「米ソムリエ」。禁止語: 最強 / 圧倒的 / 究極 / 唯一無二 / 爆発 / 神 / 無敵。

## ベースライン評価（改善前）

世界観は伝わるが、初見の操作理解と購入までの導線が弱かった（総合 6.2 / 10）。離脱の主因は興味不足ではなく「次に何をすればよいか」が弱いこと。

## 決定済み方針

1. **購買リンクは 2 行 × 3 列**（2 列折り返しにしない）
   - 通常購入: 楽天市場 / Yahoo!ショッピング / Amazon
   - ふるさと納税: 楽天ふるさと / Yahoo!ふるさと / ふるさと納税
2. **上部 CTA は最大 2 つ**。6 ボタンは詳細下部のみ
3. **味わいの輪郭**（6 項目 SVG）。名称に「レーダーチャート」は出さない
4. 文言は「探す」。EC のレジ画面にしない

## 詳細ページの情報順（実装済み）

```text
Hero → 上部 CTA（最大 2）→ この米はこんな人に → 米ソムリエメモ
  → 味わいの輪郭 → 主要指標 → 詳細指標 → 相性・季節・酒
  → 似ている銘柄 → この銘柄を探す（2 行 × 3 列 + 注記）
```

## 理想導線（ユーザータイプ別）

| タイプ | 導線 |
| --- | --- |
| A 何も分からない | 今日の一膳 → 理由 → 詳細 → 購入候補 |
| B 好みがある | スライダー → 一膳更新 → 比較 → 詳細 |
| C 料理から | 言葉検索 → 相性確認 → 購入候補 |
| D 探索 | 地図 → 点比較 → 近い銘柄 → 詳細 |
