# 編集発見・手描きビジュアル（企划）

正本は本ファイル。画面仕様の細部は [08-ui-design.md](./08-ui-design.md) §5。イラスト法務は [18-brand-illustration.md](./18-brand-illustration.md)。試験は [test-specification.md](./test-specification.md) TS-LIBRARY-04〜06。チェックリストは P2-9 / P2-10 / P2-11。

番号は [`VERSION`](../VERSION)。本機能は **1.0.0 を止めない**（P2）。地図の座標推薦式・意味検索式は変えない。

## 1. なぜ今やるか

ライブラリは検索と品評表で正確だが、初見は「辞典の索引」に見える。地図の「今日の一膳」は探針の近傍であり、日付や旬の読み物ではない。内容を厚くするには、**売り込まない編集**と**手描きの視覚**を足す。写真の転載はしない。

## 2. 非目標

- 推薦スコア・座標計算・相談 API の変更
- ホーム Desktop `100dvh` 地図の中に特集やイラスト帯を足す
- 銘柄 106 点を一度に描き切る
- LLM で特集を毎週自動生成する
- Auth / プッシュ通知 / メルマガ（「定期更新」はサイト上の暦と月次特集で足りる）

## 3. モジュール境界（解耦）

三系統は互いに import しない。地図（`FlavorMatrix`）は編集モジュールを import しない。購入（`ShopLinksStrip`）はイラストを知らない。

| 系統 | 置き場 | 責務 |
| --- | --- | --- |
| A 暦の三銘柄 | `src/lib/editorial/todaysBowl.ts` | JST 日付シードで銘柄 3。地域が重ならないよう優先 |
| B 編集特集 | `src/data/editorial/collections.ts` + `src/lib/editorial/collections.ts` | 人手の JSON。月で表に出す。catalog スコアを再計算しない |
| C 手描きアート | `src/lib/editorial/art.ts` + `public/brand-art/` | id → 銘柄画 → **県画** → 中性の産地画 → 色面。県の強調は県画のみ |

UI は `src/components/editorial/` のみ。ライブラリの品評表 `LibraryBrowser` は検索・地域・pips のまま。

命名の衝突: ホームの「今日の一膳」は座標 Top 1。ライブラリの日付枠は **きょうの三銘柄**。混ぜない。

## 4. 画面

### `/library`（レイアウト家族: 編集マストヘッド）

左または上に手描き、右に短い導入。その下が品評表。三銘柄・特集帯は置かない。

### `/discover`（ピックアップ）

ナビの一級。きょうの三銘柄はニュース行（サムネ＋県＋名＋一行の headline）。今月特集は横長の短いバナー（日付ラベル付き）。ホームでは東京日付ごと初回だけ軽い案内（localStorage、地図キャンバスの外）。

### `/collections` と `/collections/[slug]`（特集）

ナビの一級。一覧は先頭を横長バナー寄り、以降は密な行。各特集に `dateLabel`（期間）。誌面は英雄＋タイトルを寄せ、銘柄はサムネ＋headline。旧 `/library/collections/[slug]` は永久リダイレクト。

### `/library/[id]`

アートがある銘柄だけ、見出しの上に横長の手描き。県の強調は産地画の生成側（18）。ヘッダ文は重複させない（読みが名前と同じなら出さない、texture／sweetness の二重表示をやめる）。

### ホーム地図

推薦式は変えない。紙面寄りの余白・字階・スコア表示の調整のみ。特集や三銘柄を地図面に埋め込まない。銘柄詳細パネル（`BrandDetailPanel`）は導語の右に銘柄画／産地画の中図を置く（スコア横には重ねない。画が無いときは出さない）。

## 5. アイコン

Phosphor はナビ・フォームのまま。編集の節見出しだけ、既存の米粒パス（`markGeometry.ts`）から派生した **EditorialMarks**（椀・暦・蒸気）。侍・刀・キャラクターは使わない。[09-brand-icon.md](./09-brand-icon.md) に追記。

## 6. イラストの増やし方

今リリースは **産地 7（構図レシピ必須）+ 特集ヒーロー 3 + マストヘッド 1 + 代表銘柄数点**。残り銘柄は産地画にフォールバック。産地画は地図シルエットや特写で差を付ける（18）。追加は `artManifest.ts` に id を足し、`public/brand-art/brands/{id}.webp` を置く（PNG なら `npm run brand-art:optimize`）。

## 7. 計測

`editorial_bowl_click` / `editorial_collection_open`。既存イベント名は変えない。
