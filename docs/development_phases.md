# 开发阶段规划 (Roadmap)

- **Phase 0：非代码准备期（当前）**
  - 整理 30 种主流品牌米结构化数据集（CSV）。
  - 在 Supabase 中完成建表与向量索引配置。
- **Phase 1：Cursor 集中暴击期（体验期）**
  - 激活 14 天 Cursor Pro 试用。
  - 利用 Composer 自动生成 Next.js 框架、2D 矩阵组件、AI 问答路由及 RAG 联调代码。
- **Phase 2：上线与冷启动（9月中旬）**
  - 部署至 Vercel，绑定独立域名。
  - 通过 X (Twitter) 和技术社区发布 MVP，获取初期种子用户。
- **Phase 3：故乡纳税冲刺（10月 - 12月）**
  - 上线故乡纳税特供专区，最大化承接年底流量变现。
