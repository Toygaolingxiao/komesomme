# KomeSomme 与职业设计（对 GAO）

本文是**仓内定位正本**：这个 PJ 在职业与咨询事业里扮演什么角色、钱从哪来、什么故意不写进对外站。  
产品用户可见文案、UI、metadata **不要**体现「作品集 / 咨询杠杆 / B2B 试点」等叙述。

成长节奏（Phase / Wave）仍以 [20-growth-plan.md](./20-growth-plan.md) 为准。本稿管的是**为什么还要继续投时间**。

---

## 1. 一句话重定位（2026-09）

KomeSomme 首先是：

1. **可展示的一人全栈作品**——味觉一次データ、双轨推荐、百科溯源、联盟合规、Next/Supabase 上线闭环；  
2. **咨询与职涯的信任背书**——证明能把模糊领域（「挑米」）做成可运营的数据产品；  
3. 其次才是 C 端流量站。

**不要用「乐天等常规电商返利能否回本时薪」当作唯一 KPI。** 大米低客单、高可得，结构上就不适合靠大众アフィ养活 solo 站。联盟链接保留为**便利出口 + 合规练习场**，不是主商业叙事。

---

## 2. 与 Phase / Wave / Next 的对齐

| 层 | 文档 | 在职业设计里的含义 |
| --- | --- | --- |
| **Phase 1** | 検索基盤（已交付） | 证明「能上线、能被索引」——作品集的地基 |
| **Phase 2** | 米の型：見つかる → 比べる → 買う（Wave 2A 已大幅落地；2B/2C 续） | 证明「一次データ能撑着陆页与比较」——可写进案例的产品型 |
| **Phase 3** | 再訪（シェア / 自前チャネル） | 证明「环路能闭合」——再谈复制品类或卖组件才有底气 |
| **構想** | 桃 / 和牛 / 酒 Somme | 引擎横展地图；**不是**近端排期 |
| **职业主轴（本文）** | 作品集 + 咨询杠杆 | 贯穿全程；对外站不说 |
| **轻 B2B（Next·商业试验）** | 挑米診断组件 / 白标试点 | Phase 2 主体可测之后再开销售试验；**不是**自建库存 D2C |

顺序不能颠倒：

```text
Phase 2（米の型可测）→ Phase 3（再訪有信号）
        ↘
         轻 B2B 试点（可选、并行销售，不抢 Phase 2–3 主开发）
        ↘
         構想マトリクス（仅当型+再访值得复制）
```

## 3. 商业路径：取舍

| 路径 | 态度 | 理由 |
| --- | --- | --- |
| 常规モールアフィ（楽天等 %） | **维持、不加压** | 合规与 CTA 练习；不当回收时薪的主引擎 |
| 精品产直 D2C / 自营订阅履约 | **近端不做** | 销售与客诉会把一人全栈拖成米商 |
| 高 LTV「米定期便」**他人履约**的成果报酬 | **有合作方再接导线** | 客单结构对，但先谈品牌再改产品 |
| **轻 B2B**（米店／食堂／自治体向け診断嵌入） | **主试验方向** | 护城河在矩阵与 catalog，不在流量规模 |
| 作品集 / 咨询溢价 | **主回报假设** | 与 [pmo-kit](https://github.com/Toygaolingxiao/pmo-kit) 咨询交付互补：那边出册子，这边出「可跑的产品证据」 |

### 轻 B2B 的最小形状（有意向再开 Issue）

- 1 页要约（问题 / 嵌入物 / 月费或导入费 / 不含 SLA 的试点条款）  
- 可嵌入的「今夜の米」或料理別 Top N（复用现有 `pairRank` / catalog；**不**先做公网万能 API）  
- 试点 1～3 家；成功标准写进 Issue，不写进公开站  

未满足「Phase 2 主体可演示 + 至少有人愿意谈」之前，不预建多租户 SDK。

---

## 4. 对外站禁止写什么

公开页、OG、JSON-LD、ニュース、Case Study **面向用户的段落**不要出现：

- 「作品集」「个人品牌」「咨询案例」「B2B API 招商」作为主标题或ヒーロー  
- 「本站以职业发展为目的」类元叙事  

Case Study HTML（`docs/assets/`）可以对**招聘 / 顾问读者**讲技术与产品决策；那是**站外叙事物**，与 `komesomme.jp` 产品 UI 分开。产品站继续只讲：今夜の一膳、味わい、事典、お店で探す。

---

## 5. 每周仍要做的产品事（不矛盾）

职业定位不取消产品纪律：

- Phase / Wave 按 [20](./20-growth-plan.md) 推进；可感知变更仍升号  
- 联盟披露与隔离仍按 [13](./13-affiliate-compliance.md)–[15](./15-disclosure-surfaces.md)  
- Production 后填 [smoke-test.md](./smoke-test.md)  
- 百科溯源按 [pj/reviews/encyclopedia-governance.md](./pj/reviews/encyclopedia-governance.md)

差别只在**评价标准**：优先看「案例是否更好讲、数据资产是否更硬、轻 B2B 是否多一个可演示切口」，而不是「アフィ月结是否覆盖时薪」。
