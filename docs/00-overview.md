# プロダクト概要

## KomeSomme とは

KomeSomme（コメソム）は、日本のブランド米を味わいの地図から探すサイト。画面の案内役は **侍米師（じべいし）**。

食べたい料理、今日の気分、合わせたいお酒を言葉にすると、地図上の位置と銘柄の解説から、今日の一膳が見えてくる。

## 主な利用者

- 料理や気分に合う米を選びたい人
- 粒感・甘みから新しい銘柄を探したい人
- 酒・ふるさと納税返礼品を比較したい人

## 現行 MVP

番号は [`VERSION`](../VERSION)。約 106 銘柄の座標推薦、意味検索 Top 4、`/library/[id]` 事典、購入導線（通販 / ふるさと）、編集発見（ピックアップ / 特集）。匿名イベントは `access_events` + GA4（env 設定時）。本番は `komesomme.jp`。
