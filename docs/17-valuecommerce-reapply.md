# バリューコマース再申請チェック（KomeSomme）

**法律意見ではない。** 審査理由は開示されない（運営者規約第5条・登録必須事項ページも同趣旨）。本稿は [登録審査における必須事項](https://www.valuecommerce.ne.jp/registration/) と [運営者利用規約](https://www.valuecommerce.ne.jp/st_affiliate/terms.html) 第4条周辺を、公開サイトの現状に照らした**自己点検用**である。

却下メール（2026-08 頃）: サイト登録見送り、管理画面提供終了、バリューポイントクラブも同時見送り。

関連: [14-affiliate-programs.md](./14-affiliate-programs.md) §3、転鎖ゲートは `valueCommerceWrapEnabled()`。

## 1. いまの影響（コード）

| 項目 | 状態 |
| --- | --- |
| Yahoo / さとふる VC 転鎖 | **SID/PID を空のまま**。プレーン検索 URL のみ（実装済みゲート） |
| 楽天・Amazon | VC と独立。既存プログラムを継続 |
| `/terms` の「バリューコマース経由」文言 | **再承認まで**「予定／申請中」に弱めるか、VC 名を外す検討（未承認の提携を断定しない） |
| Vercel Production | `YAHOO_VC_*` / `SATOFULL_VC_*` / `VALUE_COMMERCE_WRAP` を入れない |

再申請が通るまで **転鎖を有効化しない**（規約第3・8条）。

## 2. 審査がよく見る観点 → 現状の自己評価

理由は非公開のため断定不可。公開ページから見えるリスクを優先度付きで列挙する。

### P0 — 申込フォーム／契約者（サイト改修以前）

| 点検 | なぜ | 再申請前のアクション |
| --- | --- | --- |
| 氏名・フリガナ・住所（番地まで） | 必須事項の第一項目。番地欠落・架空住所は即却下パターン | 契約者実在住所を正確入力。特商法の「請求時開示」と**申込フォームは別**——フォーム側は省略不可 |
| メール・電話が本人に届く | 確認不能だと審査不能 | 常用メール。必要なら携帯番号 |
| メディア種別 = 「サイト（Web・スマホ・ブログ）」 | 種別ミスは掲載不可 | SNS / アプリを選んでいないか確認 |
| サイト URL = `https://komesomme.jp/`（表示される本番） | 404・未公開・他者 URL は却下 | apex が 200。www を使うなら登録 URL と一致 |
| サイト名に「公式」 | 米メーカー公式と誤認されやすい | メディア名は **「KomeSomme（コメソムリエ）」** など。メーカー公式を名乗らない |
| サイト説明欄 | 審査員が「何のメディアか」を読む | 「編集評価の味わい地図・銘柄事典。外部 EC へのアフィリエイト案内」と明記。ログイン不要と書く |

### P0 — 公開サイト（審査員が開く内容）

| 点検 | 現状メモ | 推奨改善 |
| --- | --- | --- |
| 独自コンテンツの厚み | 地図・相談・ライブラリ 106 銘柄あり。薄いリンク集ではない | 維持。生成メタ（model 名）をユーザー向けに出しすぎない |
| 法務三ページ | `/privacy` `/terms` `/tokushoho` あり、ヘッダーから辿れる | 維持。トップからも一目で辿れること |
| 特商法の所在地・電話 | 「埼玉県」＋請求時開示 | ASP 審査では**フォーム側の完全住所が本命**。サイト表記は現状でも可だが、信頼感を上げるなら市区町村まで公開する選択あり |
| アフィリエイト表示 | CTA ※PR、フッター「アフィリエイト広告」、Amazon 第5条（ライブラリ／法務） | **ホーム Desktop はフッター無し**（100dvh）。審査員がトップだけ見ると開示が薄い → 再申請前にホームでも PR／規約導線が目に入るか確認。必要なら相談帯近くに短い PR 一文 |
| 未承認 ASP の断定 | `/terms` にバリューコマース名あり | 承認前は「Yahoo・さとふるへの検索案内（アフィリエイト提携は審査後）」程度に |
| 景表・誇大 | 禁止語ルールあり | 「最安」「公式認定」等を出していないか再 grep |
| ログイン壁 | 地図・ライブラリは公開 | OK。ops は別経路で審査対象外に |

### P1 — プロダクト／運用イメージ

| 点検 | 推奨 |
| --- | --- |
| 新規ドメイン・被リンク少 | GSC インデックスが進んだあと再申請の方が通りやすいことがある（保証なし） |
| AI 一括生成感 | ライブラリの「生成モデル」表記を目立ちにくく／caveats に寄せる。編集評価である旨を事典でも短く |
| 4 モール混排 | 楽天 API フィールドを混排カードに出していない現状は維持（楽天隔離） |
| 自己購入 | 自分の VC リンク経由で買わない（通った後も） |

### P2 — 再申請タイミング

| 条件 | 目安 |
| --- | --- |
| フォーム・サイト名・説明の修正 | すぐ |
| 法務／PR 文言の弱い断定を直す | 1 デプロイ |
| インデックス・コンテンツの「育った」感 | `site:komesomme.jp` で主要 URL が出てから（数日〜数週）再チャレンジする案 |
| 連投 | 短期間の連続再申請は避け、改善をまとめてから |

## 3. 再申請前の作業チェックリスト

### A. 申込（VC 画面）

- [ ] 契約者氏名・フリガナ・住所（番地）を再確認
- [ ] メディア種別: サイト（Web・スマホ・ブログ）
- [ ] URL: `https://komesomme.jp/`（本番で 200）
- [ ] サイト名から「公式」を外す
- [ ] 「サイトの内容」に: 独自の味わい評価・銘柄事典・アフィリエイトで外部 EC 案内・ログイン不要

### B. サイト（コード／本番）

- [ ] Production に `YAHOO_VC_SID/PID`・`SATOFULL_VC_*`・`VALUE_COMMERCE_WRAP` が**無い**
- [ ] `/terms` が未承認 VC を断定していない
- [ ] トップから法務リンクが辿れる
- [ ] ホームでアフィリエイトであることの手がかりがある（※PR または短い注意）
- [ ] `npm run test` / スモークで購入 4 CTA がプレーン検索のまま

### C. 通ったあとだけ

- [ ] VC で Yahoo・さとふるを**別案件**として提携申請
- [ ] 承認後に SID/PID を Production のみ設定 → Redeploy
- [ ] Preview に SID を置かない
- [ ] [14-affiliate-programs.md](./14-affiliate-programs.md) に承認日・PID 用途を追記

## 4. 通るまでの収益導線（VC 以外）

| チャネル | 方針 |
| --- | --- |
| **楽天**（主） | アフィリエイト＋（任意）API。メディア URL は `.jp`。いまの本命 |
| **Amazon**（主） | アソシエイトタグ付き検索。いまの本命 |
| Yahoo / さとふる | **検索 URL のみ**（成果なし）。UX の「探す」は残してよい |

### VC を使わない／補う選択肢

| 手段 | 向き | 注意 |
| --- | --- | --- |
| 楽天＋Amazon だけ収益化 | Web サイト向けにいちばん素直 | Yahoo・さとふるは利便導線のまま |
| [Yahoo!ショッピングアフィリエイト](https://www.lycorp.co.jp/ja/news/release/020041/)（LINEヤフー直） | 2026 開始の公式窓口。Yahoo ID で始めやすい | **主に SNS 向け**の設計。Web サイトの検索 CTA 一括転鎖とは別物。規約・リンク形式を読んでから |
| もしもアフィリエイト等の他 ASP | モール・食品案件がある場合 | Yahoo モール全体の VC 代替にはならないことが多い。案件単位で要確認 |
| A8.net / afb / AccessTrade | メーカー・米関連の単品案件 | モール横断ではなく「その広告主」だけ |
| さとふる | 多くは VC 案件 | VC なしなら検索 URL 継続が現実的 |
| ディスプレイ広告（AdSense 等） | 流量が出てから | アフィと併用可。景表・レイアウトに注意 |

**推奨（短期）:** 収益は **楽天＋Amazon** に寄せ、Yahoo・さとふるは「探せる」導線を維持。VC はサイト改善後に再申請。
