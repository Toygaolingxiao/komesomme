# 銘柄イラスト方針（手描き風）

法律意見ではない。商品写真の無断転載を避けつつ、事典・一覧に視覚を足すための正本メモ。

## なぜ写真をそのまま載せないか

- EC・メーカーの袋写真・広告写真は著作権・商標（ロゴ・パッケージ意匠）が絡む
- 「ネットの実写をそのまま使う」は不可。参照は**構図・粒の形・光の当たり方の学習用**に留め、生成物にロゴ・袋面コピー・登録商標の図形を入れない

## 採用方針

1. **参照**: 公開されている白米・炊き上がり・産地風景の実写（手元で見るだけ）。リポジトリに他人の写真をコミットしない
2. **生成**: 手描き／ガッシュ／和紙の編集イラスト。銘柄ごと 1 点（または共用プール＋産地色）
3. **禁止**: 袋・化粧箱・ブランドロゴの再現、写真のトレースに見える輪郭、他社広告の文字
4. **表記**: 画面上は銘柄名を**テキスト**で出す。絵の中に商標文字列を焼き込まない（必要なら「コシヒカリ」など品種の一般名称のみ、最小限）
5. **帰属**: `public/.../ATTRIBUTION.md` に「KomeSomme 向け生成イラスト」と日付を残す

地図 UI の点色は [08-ui-design.md](./08-ui-design.md) と `src/lib/rice/regions.ts`。下表の hex は**編集画プロンプト**用で、地図の淡色と一致させなくてよい。

## パイプライン（案）

```text
銘柄メタ（産地色・甘み帯）
  → プロンプトテンプレ（手描き・米色紙・米粒／ quanta of cooked rice）
  → 生成 → 人手レビュー（ロゴ混入・過度な写実・誇大表現）
  → public/brand-art/brands/{id}.webp または regions/{regionId}.webp
  → `npm run brand-art:optimize`（PNG 投入後に WebP 化・長辺 ≤1600、quality≈82）
  → src/data/editorial/artManifest.ts / prefectureArt.ts
```

本番ディレクトリは `public/brand-art/`（帰属は同梱 `ATTRIBUTION.md`）。解決順は銘柄画 → **県画** → 産地画 → なし（色棒のみ）。画面配線は [19-editorial-discovery.md](./19-editorial-discovery.md)。

配信: 原図は WebP。`next/image` が AVIF/WebP を再エンコード（英雄 quality 既定≈84）。`/_next/image` と `/brand-art/*` は長めの Cache-Control（immutable）。**差し替えはデプロイ必須**（同名上書きは CDN に残りやすい）。**ホーム地図は編集画を先読みしない**；推薦ホバー／詳細オープン時に **1 枚だけ** prefetch。ピックアップは首屏分だけ preload。

一覧は小さく、事典ヒーローは横長。未用意の銘柄は産地画、それも無ければ従来の色棒。

## 産地画の構図レシピ（必須）

産地 7 点は「同じ茶碗の色違い」にしない。手描きガッシュのまま、構図主軸をずらす。地図は水彩の陸塊・列島シルエット（雰囲気）であり、GIS や県名文字は入れない。産地名の「注釈」は UI テキスト側で出す。

| regionId | 構図主軸 | 色調アンカー |
| --- | --- | --- |
| `hokkaido-tohoku` | 北海道〜東北の柔かい陸塊シルエット + 遠景の霧・水田。米粒近景は小さめ | `#3F8FA3` |
| `kanto-koshinetsu` | 関東平野の開けた田 + 山脚。匙／掬いの米を特写 | `#7CA83B` |
| `tokai-hokuriku` | 夕照の収穫色が主。茶碗は画面の片側に寄せる | `#E29A35` |
| `kansai` | 近景の器・梅色の色斑。地図シルエットは極小 | `#C85A72` |
| `chugoku-shikoku` | 瀬戸内の多島シルエット + 一膳。横長構図 | `#4C9B72` |
| `kyushu-okinawa` | 南の暖色、蒸気は控えめ、光はやや硬く | `#E56B3F` |
| `national` | 抽象の列島点描 + 近景の粒。具体の県輪郭は描かない | `#8C6BB1` |

特集ヒーロー（弁当・新米・鍋・特A）も、産地画と被らないモチーフにする。生成は 1 ターン最大 2 枚。紙色と ink はブランドから外さない。

**県の強調は県画（`prefectures/{slug}.webp`）だけに載せる。** 広域の産地画 7 点は県を強調しない中性画（共用フォールバック）。解決順は 銘柄画 → 県画 → 産地画。画面側に県ラベルのピンを重ねない。全国銘柄は県画を持たない。

## 県画：区域底図 + 本県着色（必須）

単県の切り抜きだけにしない。所属する広域陸塊を水彩で描き、**本県の輪郭全体を一続きの色で塗る**（収穫金〜地域色）、隣県は低彩度の同系色。**町・市の点・丸ピン・県内の二次ハイライトは禁止**（県の中の一点に見えないこと）。図内に県名・地名文字を書かない（UI テキスト側）。近景に茶碗／米粒／稲穂を入れてよく、県の空気（霧・潮・山脚など）は余白や薄色で足す。

| 底板（産地区） | 含める県の目安 | 色調 |
| --- | --- | --- |
| 北海道・東北 | 北海道〜福島の柔かい陸塊 | 水青 `#3F8FA3`、本県は少し濃い金み |
| 関東・甲信越 | 関東平野＋甲信越の山脚（新潟含む） | 若葉 `#7CA83B` |
| 東海・北陸 | 東海〜北陸の沿岸塊 | 実り `#E29A35` |
| 近畿 | 近畿の塊 | 梅 `#C85A72` |
| 中国・四国 | 本州西＋四国（瀬戸内の多島感可） | 竹 `#4C9B72` |
| 九州・沖縄 | 九州本体＋必要なら沖縄を小さく | 柿 `#E56B3F` |

生成は 1 ターン最大 2 枚。GIS 精密トレースや印刷地図のラベル風は禁止。
