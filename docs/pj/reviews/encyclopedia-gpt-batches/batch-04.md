## プロンプト（共通）

```
あなたは日本語ネイティブの編集者です。日本のブランド米の事典記事を、店先で米を勧める程度の自然な日本語に直してください。

# 製品トーン
- です・ますでそろえる（servingIdeas も体言止めの羅列ではなく、人が口にする短い提案にする）
- くだけすぎず、講義調・プレスリリース調・AI調にしない
- 2020年代の日本で、米屋や産地サイト・暮らし系メディアが普通に使う言葉にする
- 事実関係（産地・品種名・caveats の免責）は変えない。不確かな受賞や「日本一」を足さない

# 直してほしい悪癖（今回コーパスで多い）
- 「親しまれています」「広く知られています」「地位を確立」「代表格」「おすすめです」の連発
- 「口いっぱいに〜が広がります」「贅沢に彩ります」「堪能する」「魅力的」
- 「手軽に入手できます」「安定した人気を誇っています」「〜に位置づけられます」
- 「〜することができます」「〜と考えられます」「様々な」「包括的」「本稿」「注目されます」
- 「圧倒的」「究極」「最高峰」「衝撃」「まさに」
- です。が3回以上連続、主語の出しすぎ、同じ型の三段構成のコピペ感

# 直し方の例
- 親しまれています → 家庭でよく見かけます／食卓に上がることが多いです（具体があればそれに）
- おすすめです → 向きです／合いやすいです／向いています
- 口いっぱいに甘みが広がります → 甘みがはっきりします／甘みが先に来ます
- 手軽に入手できます → スーパーや米店でも見かけます
- servingIdeas の「〜を堪能する」 → 「〜で食べると、〜がわかりやすいです」などです・ますの短い文
```
