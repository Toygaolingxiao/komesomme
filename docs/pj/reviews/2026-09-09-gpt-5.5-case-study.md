## 水平思考（跨维度）

1. **证据层 vs 叙事层**  
   多数「缺 Phase 门禁 / 缺竞品 / 缺双轨文档 / 缺 embedding 模型字段」是 **Case Study 没引用正本**，不是仓库空白。真缺口集中在：**业务数字、数据边界自报、对外算法/威胁说明**。改进 ROI：先改 HTML 叙事，再开观测出数，最后才是治理流程工程化。

2. **读者冲突**  
   若同时讨好融资与求职，必两头不讨好。定调作品集后：商业章用「计划+风险」即可，不必硬凑虚假 KPI。融资材料应另开一页，不混进 Delivery Case Study。

3. **诚实策略的升级**  
   「未計測は書かない」防假，但评委读成「没有验证文化」。正确升级是：**不写假数 + 写清何时量什么事件**（与 docs/20 SOP、21 Diff Gate 同构）。

4. **护城河时间性**  
   今天可辩护的差分=结构化+向かない+双轨不让 LLM 定事实；明天若无更新机制与质量门，差分变债。SEO Wave 2A 会放大内容面——**没有治理说明就扩 `/pair`，锐评会更狠**。故数据卡片应先于大批量 pair 页对外叙事。

5. **P0 哲学**  
   Solo Hobby 把「能回滚、能关咨询、RLS、披露」当 P0，把「出数确认」当 P1，是资源理性，不是无知。对外话术不要说「本番運用完成」，说「公開判定通过；観測闭环进行中」。
