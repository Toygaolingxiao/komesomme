## 3. 动效与交互（严苛 · 本轮焦点）

| 能力 | 1.0.0 | 1.4.1 | 严苛评价 |
| --- | --- | --- | --- |
| Lenis + ST | 有 | 有；pin VH 缩短 | 1.4.1 更不易「卡住」 |
| 矩阵探針 tour | 强 | 保留 | 持平 · 仍是最强互动 |
| 泳道描线 | 有 | 有 + **描线后矢线流光** | **1.4.1 胜** |
| Roadmap traveler | 有 | 有（钉位更新） | 内容胜在 1.4.1；动效持平 |
| 公开门控 | 静态 pipeline SVG / 表 | **ゲート回廊**：token 沿轨、闸开/绿、卡片 PASSED、轨上流光 | **1.4.1 明显胜** |
| 其他流程图 | 多静态 | lifecycle / assets 入视流光 | 有进步；ranking 双栏 SVG 仍缺流光粒子（可 β 补） |
| prefers-reduced-motion | 终态显示 | 同 + 流光停动画 | 合格 |

**仍不够「世界顶级」的地方（诚实列出）：**

1. ranking / returns 的 SVG 尚无独立粒子或步进高亮（只有静态构图 + 部分 selector 预留）。  
2. lifecycle 流光是短线段，冲击力弱于泳道长路径。  
3. 无真截图 / 无音效级微交互（α 边界）。  
4. 流光是 CSS dash 循环，不是沿 path 的真实光斑 mesh——顾问 demo 够用，Awwwards 级还差一档。
